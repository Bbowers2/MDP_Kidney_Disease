# Kidney Disease Project

Final term project for **LMU 460: Advanced Topics in Probability**.

This project uses a **Markov Decision Process (MDP)** to evaluate treatment strategies for patients with Stage 5 Chronic Kidney Disease. Value iteration and Monte Carlo simulation are used to compare conservative care, dialysis, and kidney transplantation based on quality of life, lifespan, and Quality-Adjusted Life Years (QALYs). Results indicate that **transplantation provides the highest expected QALY**, while a **fistula is preferred for patients requiring dialysis**.
